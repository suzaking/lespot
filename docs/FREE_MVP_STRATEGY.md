# 無料構成の現行方針

2026-10-21指示により、地図と一覧の両方を初期版へ含める。旧MVP0の一覧だけという縮小案は廃止。

React/Vite/TypeScript、Leaflet＋地理院タイル、非公開Sheets→CSV検証→静的JSON、Cloudflare Pages Free（未接続）、Google/Apple外部リンク。独自サーバー・DB・写真保存・従量課金APIはなし。

要件の正本はREQUIREMENTS、構成はARCHITECTURE、データ管理はDATA_OPERATIONS。確認済み施設・公開承認・実機テストの代わりに架空データや設計だけを完成扱いしない。
