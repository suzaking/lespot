# 要件 v2 — 2026-10-21

最大50人程度の名古屋周辺向け休憩検索。無料サービスだけで運用し管理負担を抑える。地図と一覧を両方提供し、スマホの表示切替・PCの横並びに対応する。

## 必須機能

- 許可ボタンからの現在地取得。拒否・失敗時は栄/久屋大通/矢場町の概略中心で検索。
- スポット名/場所、カテゴリ、料金区分、半径で絞込。直線距離順、同距離はID順。
- 一覧カード選択と地図ピン選択を共通IDで同期。ピン選択時はカードを表示・focus。
- Google施設検索/座標ピン/徒歩経路/周辺Street View、Apple位置リンク。
- 未確認設備・営業時間は表示しない。期限切れは警告し、無料/有料の確定フィルターに一致させない。
- 取得中・失敗/再試行・掲載0件・条件一致0件を区別。タイル失敗で一覧を止めない。
- 検証済みJSONのみ読み込む。編集は非公開SheetsからCSVへ書き出して取込。

## 境界

本番公開、新規サービス接続、有料化は別承認。写真・口コミ・スクレイピング・独自DB/API・アカウント機能・分析・永続GPS保存はなし。

実施設の正確な区画/入口、一般の休憩利用条件、料金、出典の利用条件を確認して登録する。空の公開データを架空データで埋めない。営業中/空席/徒歩時間は推測しない。

## 完了の区別

コード実装、単体テスト、ブラウザ検証、実機検証、実施設データ確認、公開完了を別々に記録する。全完了と呼ぶには本番相当E2Eと施設確認も必要。現状は検証記録参照。

## 2026-10-24 改訂：DB管理と地図優先

上記の「CSVからJSONへ取込」「DB/APIなし」は過去のMVP方針であり**廃止**。現行正本は`docs/DB_OPERATIONS.md`。Upstash Redisを唯一の施設DBとし、Vercel Functionsが公開読み取り・認証付き更新を仲介する。管理画面で新規登録・編集・削除できる。地図は起動時から主要表示とし、GPS取得だけを明示同意に限定する。ユーザーデータの追跡や新規写真ストレージは追加しない。
